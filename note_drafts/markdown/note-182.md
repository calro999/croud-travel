## なぜいま「鹿児島・南薩摩＆枕崎の温泉ステイ」が選ばれるのか？

冬ならではの凛とした静けさと美しい景観。街の喧騒から離れて深呼吸するだけで、日頃の緊張や頭の疲れがすっと解きほぐされていきます。

2. 身体の芯までぽかぽかに温まる本物の名湯
冷え切った身体をやさしく包み込む良質な温泉。湯船から立ちのぼる湯気と心地よいお湯のせせらぎに身を委ねる時間は、何にも代えがたい贅沢です。

黒牛会席をはじめ、この土地だからこそ味わえる旬の美味。温かい料理をゆっくりと味わいながら、夜が更けるまで贅沢な寛ぎに浸れます。
